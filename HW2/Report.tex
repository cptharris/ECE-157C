\sect{Dependencies}

The project requires Python 3.10 or later. All dependencies are listed in \texttt{requirements.txt} and can be installed with:

\begin{minted}{bash}
pip install -r requirements.txt
\end{minted}

The key packages are:

\begin{itemize}
    \item \texttt{openai} --- LLM API client
    \item \texttt{langgraph} --- agent graph framework
    \item \texttt{langchain-core} --- required by LangGraph
    \item \texttt{pandas} --- CSV loading and analysis inside generated code
    \item \texttt{json} --- data, context, and memory storage
\end{itemize}

\sect{Configuration}

The agent authenticates with OpenAI using the environment variable \texttt{OPENAI\_API\_KEY}, which should be exported:

\begin{minted}{bash}
export OPENAI_API_KEY="sk-..."
\end{minted}

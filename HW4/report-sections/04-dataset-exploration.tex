\begin{center}
    \hyperlink{https://www.kaggle.com/datasets/cnic92/200-financial-indicators-of-us-stocks-20142018}{\textit{200+ Financial Indicators of US stocks (2014-2018)}}
\end{center}

A dataset containing $223$ financial indicators for US stocks from 2014-2018. The dataset includes information on stock performance, industry, and financial metrics, and can be used for regression and classification tasks. The dataset was created using Financial Modeling Prep API and pandas\_datareader.

The dataset contains financial data for various companies from 2014 to 2018, including metrics like revenue, expenses, and profit. It is well-documented and maintained, with a high number of views and downloads. The dataset is useful for research and analysis of financial trends and company performance.

The author notes that some financial indicator values are missing (\texttt{nan} cells) and there are outliers, meaning extreme values that are probably caused by mistypings.
